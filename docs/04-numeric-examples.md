## A. m102 数值演算（《Deusmith-Memory》§9.3 示例，代码复算）

参数：Δt=7天, importance=0.8, emotion=0.5, confidence=0.9, activation=3, weight=0.6, rel=0.8。

```
S = 1 + 0.8×0.8 + 0.5×0.5 + 0.7×0.9 + 0.3×ln(4) = 2.9359
τ_eff = 7 × S = 20.5512 天
recency = exp(-7/τ_eff) = 0.7113
因子分解：rel^α=0.8000  weight^β=0.6645  recency^γ=0.8152  conf^δ=0.9000  imp^ε=0.8944  tier_boost=1.00
score = 0.3489
【勘误】原文档写 ≈0.39 —— 该值恰好是漏乘 imp^ε=0.8944 后的积 0.3900；
完整公式=0.3489，相对误差 +11.8%
```

单测钉死（tests/test_algos.py）：S、recency、score 三个值容差 ±0.0005。

## D. 可信度估计 c = sigmoid(k·(w1·auth + w2·cons + w3·ev + w4·fresh − w5·pen))


## F. 端到端场景（InMemoryStore + HashEmbedding + RuleBasedLLM）

写入序列：`请记住：我对花粉过敏。` → `我喜欢摄影。` → `我现在住在上海。(auth=0.4)`
→ `我现在住在北京。(auth=0.95)` → `我不再喜欢摄影了。`，查询：`用户的居住地和爱好`。

## G. 边界情况（--selftest 25/25 通过）

| 边界 | 行为 | 对应故障模式 |
|---|---|---|
| Δt=0 | recency=1 | 刚访问的记忆不应被衰减 |
| Δt=3650 天 | recency=0.0017 | 长期不访问趋近 0 |
| 未来时间戳 | 钳为 0 天 | 时钟回拨不产生 >1 的分数 |
| 全零因子 | floor(0.01) 兜底，score>0 | 除零/零分数导致排序失效 |
| 空候选集 | MMR 返回 [] | 空库崩溃 |
| 全同分同向量 | 确定性取 k 条 | 排序不稳定 |
| 单条候选 | 原样返回 | 单例越界 |
| 单通道第一 | rel≈0.26 而非 1.0 | 按当次最大值归一 → 阈值失效 |
| 不在任何通道 | rel=0 | 幽灵候选 |
| 敏感超门控 | score=0 | 隐私泄露（I10） |
| 边合并 1000 次 | 距 1 还差 1e-97（饱和不上溢） | 数值溢出 |
| scope 缺失 | 抛 ValueError | 跨租户越权（I1） |
| 无增益置信度 | 上限 0.711 < 0.9 | 深层晋升永久饥饿 |

## H. PostgreSQL + pgvector 延迟实测（scripts/bench_pg.py）

规模：**20,000 节点（256 维向量，HNSW）/ 200,000 边**，PG17.6 + pgvector 0.8.7，
本机便携版单实例，ANALYZE 后预热 3 轮、测 20 轮：

| 操作 | p50 | p95 | max |
|---|---:|---:|---:|
| HNSW 向量 top-50 召回 | **2.2ms** | 2.7ms | 2.7ms |
| 有界 2 跳图游走（5 种子，100/跳，生产路径） | **10.4ms** | 11.5ms | 11.5ms |
| 无界 2 跳游走（对照） | 214.5ms | 235.6ms | 235.6ms |
| 五通道全量检索（向量+图+关键词+最近+常驻） | **18.5ms** | 24.7ms | 24.7ms |

两个工程发现（已落入实现）：
1. **递归 CTE 全表扫描不可用**：2 万边规模即 150–340ms——已改为逐跳索引 BFS；
2. **图游走必须有界**：度 20 的稠密图上无界 2 跳会物化上万条子图边（214ms）；
   有界 100/跳后 10ms。管线已固定 `max_expand=100`。
