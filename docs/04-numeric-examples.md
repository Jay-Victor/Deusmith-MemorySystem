## A. m102 数值演算（《Deusmith-Memory》§9.3 示例，代码复算）

参数：Δt=7天, importance=0.8, emotion=0.5, confidence=0.9, activation=3, weight=0.6, rel=0.8。

```
S = 1 + 0.8×0.8 + 0.5×0.5 + 0.7×0.9 + 0.3×ln(4) = 2.9359
τ_eff = 7 × S = 20.5512 天
recency = exp(-7/τ_eff) = 0.7113
时效因子（v0.2.1 有界弱化）= 0.75 + 0.25×0.7113^0.6 = 0.9538
因子分解：rel^α=0.8000  weight^β=0.6645  时效因子=0.9538  conf^δ=0.9000  imp^ε=0.8944  tier_boost=1.00
score = 0.4082
【勘误①】原文档写 ≈0.39 —— 该值恰好是漏乘 imp^ε=0.8944 后的积 0.3900，原公式（无界 rec^γ）
完整复算=0.3489，相对误差 +11.8%
【勘误② v0.2.1】原公式 recency^γ 使 15 天前的记忆时效因子跌到 0.50——实测 bge 语义检索
排名 top1 的目标记忆被三个高时效节点整体挤出 top-3（"凤凰项目/安静环境/讨厌早起"垄断
榜单，证据见 docs/eval-report.md §诊断）。修正：时效因子有界弱化 (1-ρ)+ρ·rec^γ
（ρ=0.25），语义相关性重新主导排序。m102 新值 0.4082。
```

单测钉死（tests/test_algos.py）：S、recency、score 三个值容差 ±0.0005。

## F. 端到端场景（InMemoryStore + HashEmbedding + RuleBasedLLM）

写入序列：`请记住：我对花粉过敏。` → `我喜欢摄影。` → `我现在住在上海。(auth=0.4)`
→ `我现在住在北京。(auth=0.95)` → `我不再喜欢摄影了。`，查询：`用户的居住地和爱好`。

```
[system] ''
[user]   '[常驻记忆] 我对花粉过敏\n我对花粉过敏\n[记忆冲突] 关于「喜欢」存在相互矛盾的记忆，需要用户确认\n我现在住在北京\nuser: 请记住：我对花粉过敏。\nuser: 我喜欢摄影。\nuser: 我现在住在上海。\nuser: 我现在住在北京。\nuser: 我不再喜欢摄影了。'
[tool]   ''
tokens=95  degraded=False  conflicts=2
离线治理报告：{'edges_decayed': 4, 'edges_pruned': 0, 'cycles_resolved': 0,
              'summaries_created': 0, 'promoted_deep': 0, 'archived': 0,
              'consistency_warnings': 0, 'weights_renormalized': 2,
              'gini_weight': 0.0, 'weight_monopoly_warning': False}
库内统计：{'nodes_total': 5, 'edges_total': 4}
```

行为核对：①高权威纠正生效（记忆层只有「北京」；supersede 写入双时间窗口
`old.valid_to=now, new.valid_from=now`）；②否定写入进冲突提示而非覆盖；
③常驻通道（显式记住）单独成段注入，不进相关性排序（v0.2.1）；
④浅层投影（最近轮原文）附在 user 段尾部；⑤离线治理对 2 个闲置节点做了权重慢
衰减（阶段二防垄断），5 节点小场景 gini=0（健康）。

## G. 边界情况（--selftest 25/25 通过）

| 边界 | 行为 | 对应故障模式 |
|---|---|---|
| Δt=0 | recency=1 | 刚访问的记忆不应被衰减 |
| Δt=3650 天 | recency=0.0017 | 长期不访问趋近 0 |
| 未来时间戳 | 钳为 0 天 | 时钟回拨不产生 >1 的分数 |
| 全零因子 | floor(0.01) 兜底，score>0 | 除零/零分数导致排序失效 |
| 空候选集 | MMR 返回 [] | 空库崩溃 |
| 全同分同向量 | 确定性取 k 条 | 排序不稳定 |
| 单条候选 | 原样返回 | 单例越界 |
| 单通道第一 | rel≈0.26 而非 1.0 | 按当次最大值归一 → 阈值失效 |
| 不在任何通道 | rel=0 | 幽灵候选 |
| 敏感超门控 | score=0 | 隐私泄露（I10） |
| 边合并 1000 次 | 距 1 还差 1e-97（饱和不上溢） | 数值溢出 |
| scope 缺失 | 抛 ValueError | 跨租户越权（I1） |
| 无增益置信度 | 上限 0.711 < 0.9 | 深层晋升永久饥饿 |

## H. PostgreSQL + pgvector 延迟实测（scripts/bench_pg.py）

规模：**20,000 节点（256 维向量，HNSW）/ 200,000 边**，PG17.6 + pgvector 0.8.7，
本机便携版单实例，ANALYZE 后预热 3 轮、测 20 轮：

| 操作 | p50 | p95 | max |
|---|---:|---:|---:|
| HNSW 向量 top-50 召回 | **2.2ms** | 2.7ms | 2.7ms |
| 有界 2 跳图游走（5 种子，100/跳，生产路径） | **10.4ms** | 11.5ms | 11.5ms |
| 无界 2 跳游走（对照） | 214.5ms | 235.6ms | 235.6ms |
| 五通道全量检索（向量+图+关键词+最近+常驻） | **18.5ms** | 24.7ms | 24.7ms |

两个工程发现（已落入实现）：
1. **递归 CTE 全表扫描不可用**：2 万边规模即 150–340ms——已改为逐跳索引 BFS；
2. **图游走必须有界**：度 20 的稠密图上无界 2 跳会物化上万条子图边（214ms）；
   有界 100/跳后 10ms。管线已固定 `max_expand=100`。

## I. 嵌入模型对比（v0.2.1 通道修正后）

场景：61 节点七类门禁 + 14 条 dev 查询探针（期望子串进 top-3，评估关闭命中强化）。
bge = `bge-small-zh-v1.5`（本地 95MB，dim=512，查询侧带检索指令前缀）。

| embedder | 门禁 | dev 查询探针 |
|---|---|---|
| HashEmbedding-128（词法哈希，离线保底） | 7/7 | 8/14 = **0.571** |
| bge-small-zh-v1.5（真实语义） | 7/7 | 10/14 = **0.714** |

> ground truth 修正声明（v0.2.2）：p02「用户讨厌什么」原期望只认「加班」，但该开放
> 问题的任一「讨厌X」回答都语义正确——探针改为多目标（加班|早起|嘈杂）。此修正使
> 两个 embedder 口径各 +7.1pp（hash 0.500→0.571），属考卷纠错而非系统变化。

语义增益 **+14.3pp**（0.571→0.714）。修正前（v0.2.0 通道缺陷下）两者同为 0.214——recency 无界衰减
+ recent/通用词通道让高频节点垄断所有查询，语义升级被完全遮蔽。v0.2.1 修正集：
①时效因子有界弱化 `(1-ρ)+ρ·rec^γ`（ρ=0.25）；②recent 通道移出 RRF 融合（连续性
由浅层投影承担）；③keyword 通道只收稀有 term（df<10，通用二元组不参与）；④常驻
通道不进融合（单独成段注入）；⑤评估探针关闭命中强化（测冷启动排序，非先发优势）。

bge 侧剩余 MISS 属小模型的弱语义对（"在哪个城市"↔"我现在住在北京"、
"办公设备"↔"双显示器"等），属模型能力边界而非管线缺陷——换 bge-base/large
可继续提升。

## J. 参数校准（bge 口径，v0.2.2）

`calibrate.py --embed local` 在真实模型下单维扫参（dev 14 条，其余参数固定默认；
修正后 bge 基线 **0.714**）：

- **mmr_lambda**（0.5–0.9）：0.5→0.571、0.6→0.643、0.7/0.8/0.9→0.714 平台——
  低于 0.7 时多样性惩罚过重挤出相关项；**默认 0.7 恰在平台起点，保持**；
- **score.gamma**（0.3/0.6/1.0）：0.3→**0.786**（+7.1pp）、0.6→0.714、1.0→0.571
  （-14.3pp）——**单调方向梯度**：γ 越小时效影响越弱、纯语义排序越强，与
  v0.2.1 时效有界化是同一方向的延伸。gamma=0.3 下七类门禁 7/7 无退化
  （G1 陈旧值/G6 无关精度健康，G4 摘要排名反升至 @2）。
- **score.beta / topk_recall**（hash 口径先导）：全线持平。

**决策：全部保持默认。** gamma=0.3 的 +7.1pp 是 1 条探针的差异（dev=14 的分辨率
极限 ±7.1pp），虽有单调方向与门禁无退化双重佐证，改全局参数仍属拟合考卷——记为
**候选优化方向**，待探针集扩至 ≥50 条后复验（held-out 已于 v0.2.0 消费，届时一并重建）。
