## 对照实验：相似度判据 vs 槽位+极性（评审错误#1）

- 否定对（如「我喜欢摄影」↔「我不再喜欢摄影了」）余弦相似度：min=0.557，max=0.738，mean=0.655
- 良性改写对（如「我喜欢摄影」↔「我热爱摄影」）余弦相似度：min=0.323，max=0.760，mean=0.504
- 两类区间重叠且否定侧整体更高：**任何能合并良性改写的阈值 θ 必然吞掉否定更新；任何保得住否定更新的 θ 连良性改写都合不了——相似度判据不可用。**

| θ | 否定更新丢失 | 良性改写合并 |
|---|---|---|
| 0.4 | 4/8 | 4/8 |
| 0.5 | 5/8 | 4/8 |
| 0.6 | 6/8 | 3/8 |
| 0.7 | 2/8 | 2/8 |
| 0.8 | 0/8 | 0/8 |
| 0.9 | 0/8 | 0/8 |

槽位+极性判定：否定更新保留 **8/8**（丢失 0）；真重复（同槽位+同宾语+同极性）由 is_duplicate 正确合并；多值谓语（喜欢）换宾语不误判为冲突（单值谓语如「住在」换宾语才算冲突）。

## 污染声明

本探针集在开发过程中曾用于发现并修复：多值谓语冲突误判 bug（『喜欢摄影』与『喜欢跑步』曾被误判为冲突）。**它已是被污染的开发集**——正式调参前请按 70/30 切分 dev/held-out，另建留出集，且留出集不得用于修 bug。

## 已知缺口（不进门禁，单列）

- HashEmbedding 为词法级占位实现，改写问法的召回质量显著低于真实语义模型；
- 图游走为简化 PPR（2 跳衰减），未与真 PPR/Neo4j 对照；
- 多用户并发与 PG 后端下的检索延迟未在本报告覆盖（见 docs/04）。
